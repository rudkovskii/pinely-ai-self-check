# Короткий опрос AI-самооценки (Pinely) — как этим пользоваться

Три файла, всё статика, без сборки и без интернета:

| Файл | Что это |
|---|---|
| `16-Опрос-самооценка.html` | Сам опрос. Один файл, картинки вшиты внутрь. Открывается двойным кликом. |
| `16-Выбор-визуала-карты.html` | Витрина: все 5 визуалов карты уровней друг под другом. Для выбора вместе с заказчиком. |
| `decode.html` | Декодер ответов: вставляешь строки из Slack → таблица → CSV. |

---

## 1. Выбрать визуал (сделать один раз)

В опросе Вопрос 2 — «карта уровней». Есть 5 вариантов картинок:

- **Trees** — новогодние ёлочки (росток → наряженная ёлка)
- **Growing tree** — росток с корнями, зелёный
- **Summit** — восхождение на вершину
- **Icons** — абстрактные иконки (глаз, колба, шестерня, кубы)
- **Halftone dots** — точечная гора, рисуется прямо в коде, без картинок

**Как выбрать:** открой `16-Опрос-самооценка.html` — вверху жёлто-зелёная плашка «Visual style — for review». Кликай варианты и смотри карту в живом опросе. Или открой `16-Выбор-визуала-карты.html`, где все пять сразу.

**Как зафиксировать выбранный:** открой `16-Опрос-самооценка.html` в текстовом редакторе, найди блок `const CONFIG` в начале `<script>` и поправь две строки:

```js
VISUAL_STYLE: 'dots',      // ← впиши выбранный: 'trees' | 'sprout' | 'mountains' | 'icons' | 'dots'
SHOW_SWITCHER: true,       // ← поставь false, чтобы убрать плашку выбора перед выкаткой
```

Всё. Плашка исчезнет, останется один выбранный визуал.

## 2. Выложить на GitHub Pages

1. Создай репозиторий на GitHub (например `pinely-survey`).
2. Залей туда `16-Опрос-самооценка.html` и `decode.html`. Удобно переименовать опрос в `index.html` — тогда ссылка будет короткой.
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / root → Save**.
4. Через минуту появится адрес вида `https://<логин>.github.io/pinely-survey/`. Это и есть ссылка для сотрудников.
5. Декодер лежит там же: `.../pinely-survey/decode.html` — но его никому не даём, он только для тебя.

Картинки вшиты в html, отдельная папка `img/` не нужна.

---

## 3. Как собрать ответы

1. Сотрудник открывает ссылку, отвечает, жмёт **Copy my answers** — в буфер копируется одна строка.
2. Он вставляет её в тред опроса в Slack.
3. Ты открываешь `decode.html`, вставляешь **все строки из треда** (по одной на строку), жмёшь **Decode** → таблица.
4. **Download CSV** — файл открывается в Google Sheets / Excel.

Ничего никуда не отправляется автоматически: и опрос, и декодер работают только в браузере.

---

## 4. Что можно править без программиста

Всё в блоке `const CONFIG` в начале `<script>` файла `16-Опрос-самооценка.html`:

- `TEAMS` — список команд в выпадашке.
- `LEVELS` — названия и описания пяти уровней (есть `en` и `ru`).
- `TASKS` — 10 типовых задач (чекбоксы).
- `STRINGS` — все видимые надписи (заголовок, подсказки, кнопки). Есть `en` и `ru`.
- `LANG: 'en'` — переключить весь интерфейс на русский: поставить `'ru'`.

После правок просто сохрани файл — пересобирать ничего не надо.

---

## 5. Заменить картинки уровней (по желанию)

Картинки нарезаны из присланных полос и вшиты в html как base64 (объект `TILES` перед `CONFIG`). Если захочешь заменить конкретный набор своими картинками — проще прислать мне новую полосу, я перенарежу и вшью. Вручную это делать не нужно.

Вариант `dots` картинок не использует вообще — он рисуется кодом и меняется только числами в функции `dotsSVG`.
